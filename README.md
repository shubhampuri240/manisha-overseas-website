# Manisha Overseas Website

The permanent source repository for the Manisha Overseas editorial website.

## Project structure

- `index.html` — homepage
- `dress-studio.html` — interactive 3D dress studio
- `about.html` — About Manisha Overseas
- `collections/` — seven collection category pages
- `products/` — product detail pages
- `assets/` — CSS, JavaScript, favicon and image assets
- `manufacturing.html`, `private-label.html`, `wholesale.html`, `quality.html`, `contact.html`
- `fabrics-craftsmanship.html`, `buyer-process.html`, `pages.html`

## Local preview

Open `index.html` in Chrome or Edge. Internet access is required for web fonts and the Three.js runtime used by the 3D dress studio.

## Safe edit and publishing workflow

1. Keep `main` as the approved version.
2. Make larger changes on a separate branch or staging copy.
3. Test desktop, mobile, page links, images, forms and the 3D studio.
4. Merge only approved changes into `main`.
5. Deploy the approved version to Hostinger after hosting and domain access are connected.

## Content management

This repository is the source-code and version-history home. It is not itself the visual product dashboard. A WordPress/CMS editing dashboard can be added later without rebuilding the approved design.

## Important

- Keep this repository private.
- Never commit passwords, API tokens, private buyer information or live enquiry records.
- The `storage/` folder is runtime-only. Do not commit enquiry data.
- Some fashion, textile and factory visuals are illustrative concepts. Replace them with approved Manisha product and Noida facility photography before presenting them as documentary images.
- The 3D dress is an original conceptual interpretation of the supplied reference, not a scan or production tech pack.
- This repository is not yet deployed to Hostinger.
